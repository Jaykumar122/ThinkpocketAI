Under The Hood

Precision engineering.
From C++ to Dart.

Clean Architecture separation across presentation, domain, and native C++ runtime.

Native Bindings
llama.cpp via FFI

Compiled using Android NDK 28 with CMake. Leverages ARM64-v8a NEON SIMD vector extensions for ultra-fast on-device matrix multiplication.

Concurrency
Dart Background Isolate

All token generation occurs on an isolated memory thread. Zero UI blocking or frame dropping on 120Hz displays.

Local Database
Drift SQLite Engine

Full local session persistence, token analytics, audit logs, and document chunk storage completely offline in encrypted SQLite.

Hardware Compatibility
Android 8.0+ (API 26)

Targeted to API 36 with 64-bit ABI support. Dynamically checks available RAM to prevent Out-Of-Memory (OOM) crashes.
